整理好資料夾
✅ 在家遠端也能用！只要登入公司 Google 帳號，直接存取共用雲端硬碟，不需要在家電腦安裝任何東西。
Drive 路徑：01_1.影音設計部 → 品牌資料夾 → 商品頁 → 產品資料夾 → 示意圖
1

打開這個 HTML 檔案，用 Chrome 開啟

點兩下 HTML 檔案，用 Chrome 或 Edge 開啟。在家或在公司都可以用，不需要任何安裝。

2

點「登入 Google 帳號」

用你的公司 Google 帳號登入授權，讓工具可以存取共用雲端硬碟。

💡 登入一次後，當次使用都不用重新登入。下次打開工具需要再登入一次。
3

選擇品牌

工具會自動從共用硬碟列出所有品牌（01~13 以及未來新增的），點選你要處理的品牌。

4

上傳業務給你的設計申請 PPT

把 .pptx 檔案拖曳進來，或點框框選擇。工具會自動讀取裡面的商品名稱。

解析完後確認商品清單，有漏掉的可以手動加入，確認後按「開始搜尋」。

5

選圖，打包下載

搜尋完成後，圖片會按商品分組顯示。點圖片選取，或按「全選此商品」，選好後按下方「打包下載 ZIP」。

✅ ZIP 裡面依照商品整理好資料夾：
📁 魚油 ／ 📁 腸胃益生菌 ／ 📁 關節粉 ／…

⚠️ 解壓縮小提醒

Windows 內建解壓縮有時中文資料夾名稱會空白，建議用免費的 7-Zip 來解壓縮。

在家遠端可以用嗎？▼
可以！只要用瀏覽器打開這個 HTML 檔案，點登入 Google，用公司帳號授權，就能直接存取共用雲端硬碟，不需要在家電腦安裝 Google Drive for Desktop。
找不到某個品牌的資料夾？▼
工具會自動列出你的帳號在「01_1.影音設計部」底下有存取權限的所有品牌資料夾。如果看不到某個品牌，可能是你的帳號沒有該品牌的存取權，請聯絡管理員開通。
商品名稱解析錯了怎麼辦？▼
解析完後有確認步驟。名稱不對的點「✕」刪掉，有漏掉的在輸入框手動加入，再按「開始搜尋」。
搜尋結果顯示「未找到」某個商品？▼
工具會在該品牌的「商品頁」資料夾底下的「示意圖」資料夾裡搜尋。如果找不到，可能是商品資料夾裡沒有「示意圖」子資料夾，或是圖片還沒上傳到 Drive。
下載的 ZIP 打開是空的？▼
用 7-Zip（7-zip.org，免費）解壓縮就正常了，Windows 內建解壓縮對中文資料夾名稱支援不好。
這個工具安全嗎？▼
安全。工具透過 Google 官方 OAuth 登入，只讀取你帳號有權限的資料，不會把任何資料傳到其他伺服器。登出後存取權限立即失效。
